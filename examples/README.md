# G2 Scraper API – code examples

Examples for every G2 endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/product_info.sh`](curl/product_info.sh) | `bash product_info.sh` |
| PHP | [`php/product_info.php`](php/product_info.php) | `php product_info.php` |
| C# | [`csharp/ProductInfo.cs`](csharp/ProductInfo.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/product_info.go`](go/product_info.go) | `go run product_info.go` |
| Java | [`java/ProductInfoExample.java`](java/ProductInfoExample.java) | `java ProductInfoExample.java` |
| Ruby | [`ruby/product_info.rb`](ruby/product_info.rb) | `ruby product_info.rb` |
| Node.js | [`nodejs/product_info.mjs`](nodejs/product_info.mjs) | `node product_info.mjs` |
